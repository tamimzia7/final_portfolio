# Tamim Zia — Portfolio

World-class portfolio website built with React, TypeScript, Vite, and Three.js.

## Stack

- React 18 + TypeScript
- Vite 6
- Tailwind CSS 3
- GSAP + Framer Motion
- Three.js + React Three Fiber + Drei
- Lenis (smooth scrolling)

## Getting Started

```bash
npm install
npm run dev
```

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start dev server |
| `npm run build` | TypeScript check + production build |
| `npm run preview` | Preview production build |
| `npm run lint` | Run ESLint |

## Build

```bash
npm run build  # outputs to dist/
```

## Design

- Dark luxury theme (`#050505` background)
- Purple/cyan gradient accents
- Glassmorphism cards with `blur(40px)`
- 28px border radius everywhere
- Smooth scroll with Lenis
- Aurora background + noise overlay
- 3D scene with R3F
- Magnetic buttons + cursor glow
